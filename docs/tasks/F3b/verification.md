## Gaps

- **Real bookings backend not exercised**: `Bookings` is refused in `API_REAL_TAGS` until contract request
  004 lands; everything here is against Prism's examples. Idempotency on the server depends on contract
  request 005.
- **Prism can't simulate**: re-pricing over time, rate limits per IP/device, a booking with several
  system sizes or legs without `fixture_id` (covered by unit/component tests on edited examples).
- **Amharic copy** for bookings is composed (TRANSLATION-NOTES "Booking codes (F3b)" and "F3b
  verification"), not authored — needs native review before launch.
- **Dev-only console warning** on any `notFound()` page (U1): harmless in production, but it hides real
  errors in dev until the root layout's theme script is reworked.
