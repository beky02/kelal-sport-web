## Understanding

Today an activated terminal shows "This terminal is ready" and nothing else. F8ca puts the sportsbook
there. A walk-in customer picks a sport and a day, sees the competitions and matches with their prices in
large type, taps prices into a slip panel and removes them again, and switches between Amharic and English
with one tap. The kiosk starts in the tenant's default language. The kiosk reuses the player's catalogue
loaders, mappers, board filters, slip store and pure views, behind its own `/api/terminal/*` routes and its
own large-format components. To make that possible, the shared text hooks stop reading the player's
store. A tenant that has switched shop betting off (`features.retail: false`) shows no sportsbook. No money
is computed or shown in F8ca.

## Design

```
TerminalApp ─ status active, shop open ─▶ Kiosk ─ useTerminalConfig ─▶ KioskLocale (LocaleProvider ← kiosk store, <html lang>)
                                                                    ├▶ retail off → TerminalShell + TerminalUnavailable
                                                                    └▶ KioskSportsbook
KioskSportsbook: KioskTopBar (shop · label · language) │ KioskSportTabs · KioskDayStrip · KioskBoard │ KioskSlip
           useKioskSports ─ terminalRead ─▶ GET /api/terminal/catalogue/sports ─▶ loadSports (anon)
           useKioskBoard(filters) ────────▶ GET /api/terminal/catalogue/board  ─▶ loadBoard (anon)
           useTerminalConfig ─────────────▶ GET /api/terminal/config           ─▶ loadPublicConfig → toTerminalConfigView
```

**Contract operations** (anonymous, tags `Catalogue` and `Config`): `listSports`, `listEvents`,
`getDictionary` (through `loadSports`/`loadBoard`), `getPublicConfig` (through `loadPublicConfig`, cached
per tenant for 60 s). No new upstream call is written. The routes reuse the loaders.

**Server**

- `lib/server/terminal.ts`: `activeTerminal(request)`, shared by the three reads. It runs
  `terminalOnly`, then reads the terminal cookie of this tenant. It returns the session, or a 401 Problem
  (`AUTH_INVALID_CREDENTIALS`, "This terminal is not activated") before anything else. `readTerminalSession`
  is unchanged.
- `app/api/terminal/catalogue/sports/route.ts`: `activeTerminal` → `respond(loadSports)`.
- `app/api/terminal/catalogue/board/route.ts`: `activeTerminal`, then `boardQuery` (in `lib/server/terminal.ts`),
  which checks the query before it goes anywhere (decision 14). Anything else is a 400 `VALIDATION_FAILED`
  with `errors[]`, and nothing is called. Then `respond(preMatchBoard(loadBoard(tenant, { sportId, date,
filter }, false)))`. The kiosk never asks for `live`, `competition` or `lite`.
- `app/api/terminal/config/route.ts`: `activeTerminal` → `respond(loadTerminalConfigView)`.
- `lib/server/public-config.ts`: `loadTerminalConfigView(tenant)`.
- `lib/api/mappers/config.ts`: `toTerminalConfigView(config)` →
  `{ retail: features.retail !== false, languages, defaultLanguage }`. The contract's `Language` enum
  already limits the list to `am`/`en`. A default the list doesn't hold falls back to its first, and an
  empty list to the default. F8cb adds `rules` (`retail_betting`). The view
  carries no `betting`, so the kiosk cannot reach the online rule set by mistake.

All three go through `respond()`: `no-store`, Problems passed through. They forward no `Prefer` at all
(the player's catalogue loaders take none); the kiosk's error and empty screens are made in Playwright by
answering its own routes, as F8b's are.

**Domain** (`features/terminal/types.ts`)

```ts
interface TerminalConfigView {
  /** `features.retail`: off only when the tenant says `false`. */
  retail: boolean;
  /** The tenant's languages, in its order; the kiosk switches among them. */
  languages: Lang[];
  defaultLanguage: Lang;
}
```

`terminalConfigSchema` goes in `lib/api/terminal-schemas.ts`, with `satisfies z.ZodType<TerminalConfigView>`.
The board and sport answers are checked by `boardSectionSchema` and `sportSchema`, now in
`lib/api/catalogue-schemas.ts`.

**Browser** (`features/terminal/`)

- `lib/calls.ts`: `TERMINAL_READS = { config, sports, board }`. These are routes of unsigned GETs that
  each compose several API calls, so there is no `api` path to sign.
- `api/client.ts`: `terminalRead(route, schema, { params, signal })`, with the same errors and answer
  checks as `terminalRequest`, minus signing. Both send the kiosk's language as `Accept-Language`
  (`kioskLanguage()`, from the kiosk store; Amharic until a config says otherwise, as before).
- `api/kiosk.ts`: `getTerminalConfig()`, `getKioskSports()`, `getKioskBoard({ sportId, date, filter })`.
- `hooks/use-kiosk.ts`:
  - `useTerminalConfig()`: `terminalKeys.config()`, 60 s stale. Refetched every 5 minutes while retail is
    on, every 60 s while it is off.
  - `useKioskSports()`: `terminalKeys.sports()`.
  - `useKioskBoard(filters)`: `terminalKeys.board(filters)`, `STALE_TIME.events`, refetched every
    `ODDS_REFRESH_MS`.
  - All three use `useStatusOnRefusal`: a 401 invalidates the status query.
- `stores/kiosk.store.ts`: `{ chosen, choose, reset }`, never persisted, and the pure
  `kioskLanguage(chosen, config)`: the choice while the tenant offers it, else its default, and Amharic
  before there is a config. _(Changed in review, Q3: no copy of the config's default in the store.)_
- `components/kiosk/`:
  - `Kiosk` (the gate): its states are config loading, then `TerminalLoadingMessage`; error,
    `TerminalOfflineMessage` with Try again; retail off, `TerminalUnavailable`. The first three sit in
    `TerminalShell`. Otherwise `KioskSportsbook`. All of it is inside `KioskLocale`.
  - `KioskLocale`: `LocaleProvider` `{ lang: kioskLanguage(chosen, config), clock: "eat", calendar:
"gregorian" }`. It sets `<html lang>`, and restores the value it found when the kiosk leaves (review
    Q10).
  - `KioskSportsbook`: the layout. At `lg` and up, the board and the slip side by side. Below it, the slip
    is a view opened from a bottom bar that counts the picks.
  - `KioskTopBar`: shop name, terminal label, and the language switch, a button labelled with the other
    language's own name (`LANG_NAME`). _(Changed while implementing: its own header, not composed into
    `TerminalShell`.)_
  - `KioskSportTabs`, `KioskDayStrip` (today plus 5 days, EAT, Gregorian, "Today" first), and
    `KioskBoard` (competition headers and rows; a loading skeleton; empty with "Show football", the
    player's reset to the start; error with Try again).
  - `KioskEventRow`, with `KioskOddsButton` (`OddsButtonView size="lg"` wired to the slip store and
    `oddsAriaLabel`), and `KioskSlip` (the picks, Remove, Clear all, the empty state).
- `components/TerminalApp.tsx`: an open shop's terminal renders `Kiosk`. `TerminalReady` goes.
  `components/TerminalScreens.tsx` gains `TerminalUnavailable`, and the message parts of loading and
  offline (`TerminalLoadingMessage`, `TerminalOfflineMessage`) so they can sit under the shop's bar.
- `app/(terminal)/terminal/page.tsx`: `<Suspense>` around `TerminalApp` (for `useSearchParams`). The
  fallback is `TerminalLoading`.

**Shared**

- `lib/i18n/locale.tsx` (new): `Locale`, `LocaleProvider`, `useLocale()`.
- `lib/i18n/use-translation.ts`, `rich.tsx`, `use-date-time-text.ts`, `use-long-date-time-text.ts` read
  `useLocale()` instead of `ui.store`.
- `app/(player)/locale.tsx` (new): `PlayerLocale`, which turns `ui.store`'s `lang`, `clock` and `calendar`
  into a memoised value for `LocaleProvider`. It is mounted in `(player)/providers.tsx` and in
  `tests/component/render.tsx`.
- `features/odds/components/OddsButtonView.tsx`: `size: "lg"` (56 px, 18 px type). The other sizes are
  unchanged.
- `lib/api/catalogue-schemas.ts` (new): the sport and board schemas, moved. `schemas.ts` re-exports them.
- `lib/query/keys.ts`: `terminalKeys.config()`, `.sports()` and `.board(filters)`.
- `lib/i18n/index.ts`: `LANG_NAME`, each language's name in itself (English, አማርኛ). It is the same in both
  catalogues, so it isn't in them.

**Errors handled and what the screen offers**

| Where                | Answer                                          | Screen                                                                         |
| -------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------ |
| config               | loading                                         | the shop's bar + "Starting the terminal…" (bilingual)                          |
| config               | network / 5xx / unreadable, no config yet       | the shop's bar + "Can't reach the server" + Try again (bilingual)              |
| config               | `retail: false`                                 | `TerminalUnavailable` (bilingual, no controls)                                 |
| any kiosk read       | 401 (`AUTH_INVALID_CREDENTIALS` from our route) | the status query is invalidated; its answer decides (activation, switched off) |
| sports / board       | loading                                         | skeleton rows                                                                  |
| board                | `[]`                                            | "No matches right now · Try another sport or day" + "Show football" (`reset`)  |
| board                | network / 5xx / unreadable                      | "Couldn't load matches" + Try again (refetch)                                  |
| sports               | network / 5xx / unreadable                      | no tabs; the board, on its default sport, says what it can                     |
| board, already shown | a later poll fails                              | nothing changes; the next poll tries again                                     |
| board route          | bad `sport` / `date` / `filter`                 | 400 `VALIDATION_FAILED` with `errors[]` (never reached from the UI)            |

**i18n**: the kiosk reuses the player's keys wherever the words are the same: `nav.sports`,
`nav.slipAria`, `board.filters.today`, `board.empty.title`/`action`, `board.error.*`, `betSlip.title`,
`clearAll`, `emptyTitle`, `emptyBody`, `remove`, `suspended` and `common.retry`. New `terminal.kiosk.*` keys,
in both catalogues: `matches`, `days`, `emptyBody` ("Try another sport or day.", since the kiosk has no
filter), `backToMatches`, `unavailable.title` and `unavailable.body`. _(Changed while implementing: the
planned list was longer and duplicated existing keys. "The stake and your code come next" was dropped:
copy about what F8cb/F8cc will do has no place before they do it.)_ `terminal.ready.*` is removed. All
composed Amharic is in `TRANSLATION-NOTES.md`.

**Feature flags**: none new. `features.live` stays off; the kiosk asks for no live board.

## Risks

- **Money.** None is computed or shown in F8ca. The slip store is shared, unchanged. Prices are the
  contract's strings, formatted for display only. The online/retail price gap (decision 2) is the
  engine's and the POS's to resolve, and is a gap until 015 is answered.
- **Security.** The new routes check the host first and need an activated terminal of this tenant. The
  board's query is validated before it reaches an upstream URL. Everything goes through `respond()`
  (`no-store`). No `Prefer` is forwarded. No new header reaches the API. The kiosk
  never calls a player route (test), and the proxy is unchanged.
- **The player's screens.** The text hooks change their source. A screen outside a `LocaleProvider` would
  fall back to English. Every player page sits under `Providers`, and every component test under
  `render.tsx`. The full component suite and `pnpm ui` cover the player.
- **Accessibility.** Targets of at least 48 px (measured in Playwright). Prices keep `oddsAriaLabel` and
  `aria-pressed`. The language switch is a button named with the other language's own name (English, አማርኛ), with `lang` set to it. Every Amharic line
  carries `lang`.
- **Performance.** One board request per sport and day, polled every 30 s (D5), as on the player site. The
  kiosk's bundle loads no player schema module (decision 6) and nothing under `src/stores/`.

## Out of scope

- Match detail and more markets on the kiosk, search, competitions, live.
- Signed catalogue reads (request 015).
- Showing the kiosk's language on F8b's system screens.
