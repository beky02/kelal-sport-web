## Understanding

One Next.js build serves two sites. Today's player pages move, with their history, into a `(player)`
route group whose `layout.tsx` is the root layout they already have, so no URL and no pixel changes. A
`(terminal)` group gets its own root layout and a placeholder page at `/terminal`; F8b builds the
terminal there and its route handlers under `/api/terminal/*`. Which site a request is for is decided by
its host: a host listed in a new `TERMINAL_HOST_MAP` is a shop terminal (and names its tenant), every
other host is the player site as today. The proxy then runs on every page and route handler and keeps
each host to its own routes: a terminal host serves only `/terminal/*` and `/api/terminal/*` (its `/`
shows `/terminal`), a player host never serves them, and anything else answers 404 — exactly as a route
that doesn't exist.

## Design

No contract operation, no loader, mapper, hook or query key: F8a is routing.

**Folders**

```
src/app/(player)/layout.tsx        today's root layout (git mv), imports ../globals.css and ../fonts
src/app/(player)/providers.tsx     git mv
src/app/(player)/page.tsx, b/, competition/, event/, help/, live/, login/, my-bets/, privacy/,
                 profile/, register/, responsible-gaming/, t/, telegram/, terms/, transactions/, wallet/
src/app/(terminal)/layout.tsx      new root layout: <html lang="am" data-theme="dark">, fonts, tokens
src/app/(terminal)/terminal/page.tsx  the placeholder (/terminal)
src/app/api/…                      unchanged; /api/terminal/* is F8b's
src/app/globals.css, favicon.ico   shared, unchanged
src/app/fonts.ts                   Barlow, Barlow Condensed, Noto Sans Ethiopic (moved out of the layout)
```

**Hosts** — `src/lib/server/config.ts`: `terminalHostMap` in the schema (refined: no host in both maps),
parsed from `TERMINAL_HOST_MAP` with the non-production default; `isTerminalHost(host)`;
`tenantForHost(host)` reads `tenantHostMap`, then `terminalHostMap`, then `defaultTenant`.

**Paths** — `src/config/routes.ts`: `terminal: "/terminal"`, `terminalApi: "/api/terminal"`,
`notFound: "/_not-found"`.

**Proxy** — `src/proxy.ts`:

```
proxy(request)
  terminal host?  "/"                        → rewrite to /terminal (query kept)
                  /terminal…, /api/terminal…  → next()
                  anything else               → rewrite to /_not-found, 404
  player host:    /terminal…, /api/terminal…  → rewrite to /_not-found, 404
                  /t/{x}                      → today's ticket address check
                  account pages, no cookie    → today's redirect to /login?next=
                  anything else               → next()
config.matcher = ["/((?!_next/|favicon\\.ico$|flags/).*)"]
```

It still never opens the session cookie and nothing trusts it beyond the split itself.

**`next.config.ts`** — `experimental.proxyClientMaxBodySize: "32kb"` (decision 9).

**`package.json`** — `verify`: `… && pnpm build && node scripts/check-host-split.mjs && pnpm ui`.

**i18n** — `terminal.placeholder.title`, `terminal.placeholder.body` (en, am); TRANSLATION-NOTES.

**Feature flags** — none. Release 2 flags untouched.

**Error codes** — none: no API call.

## Risks

- **Security — the split is the proxy's.** Covered by the unit tests above (both hosts, spellings, the
  matcher over every route) and the Playwright check. A request that skips the proxy reaches what a guest
  could reach anyway: player handlers need the host-bound session cookie; F8b's handlers will check the
  host themselves (decision 15).
- **Security — memory.** The proxy now sees every route handler's body; capped at 32 KiB (decision 9).
- **Security — host spoofing.** The host is read only as tenants are (decision 5); a forged
  `X-Forwarded-Host` is ignored without a trusted proxy (test).
- **Money** — none touched.
- **Accessibility** — the placeholder: one `h1`, `lang` on each language block, tokens for colour.
- **Performance** — one map lookup per request; no I/O. A CDN in front must key `/` on the host (it does
  by default); FD1's two deployments make that moot.
- **Regression** — every screen compared pixel by pixel (AC-2); the e2e suites (auth, booking, ticket,
  security headers) run unchanged against the moved pages.
