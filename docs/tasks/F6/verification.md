## Gaps

- **The shared dev server.** The first `pnpm verify` lost the dev server mid-run (48 UI failures, all
  `ERR_CONNECTION_REFUSED` / `ERR_EMPTY_RESPONSE`); a new `pnpm dev` was started from the VS Code terminal
  outside this session. The second run failed once on Chrome timing out creating a browser context in
  `auth.spec.ts` (that spec passed alone 21/21). During review round 1 the dev server kept a stale copy
  of the wallet types module after a new export (`TypeError … reading 'includes'` from
  `/api/wallet/transactions`, while a production build served it correctly); Next's own dev-tools restart
  (`/__nextjs_restart_dev?invalidateFileSystemCache`) fixed it, and the `next dev` in the terminal kept
  running.
- **`balance_after` per kind** is not defined by the contract; the line is left out for bonus kinds and
  "Other" until it is (contract request proposed in the report).
- **Prism has no failure for the wallet or the history**: their error screens are answered in the browser.
- **The deposit and withdrawal flow is still the mock** (F6b, F6c): F6a should not reach players before
  they land.
