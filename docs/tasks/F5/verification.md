## Gaps

- **No scanner yet.** The barcodes decode from the screenshots' pixels (UI review), but no shop scanner
  has read one off a phone screen; worth a check at the first shop test (C19).
- **Prism cannot show the engine's own behaviour**: re-pricing under the odds policy (every 409 is canned),
  the idempotent replay of a ticket for a repeated key, or a retry racing an in-flight first try. The
  route forwards the key unchanged (tested); the replay is C08 §2's promise; the race is 007 item 4.
- **An unconfirmed bet does not survive a reload** (M5). A reload loses its key, and the same slip built
  again would go with a new key. It belongs with persisting the slip (C18 §4.2, not built yet).
- **My bets and the wallet are still mocks** until F5b and F6, so after "no answer" nothing in the app
  can show whether the bet exists; only Try again (same key) can.
- **No Prism examples** for `BET_MARKET_SUSPENDED`, `BET_STAKE_TOO_HIGH`, `BET_LIMIT_EXCEEDED` and the RG
  refusals: proven with the contract's Problem shape and answers given in the browser (007 item 3).
- **`potential_payout` net or gross** is not written down (007 item 2); the label claims nothing.
- **`real_money_enabled`** (false in Prism's config) is not read: F1 shows that notice.
- **Composed Amharic** for every new string needs a native speaker's review (TRANSLATION-NOTES.md).
- **Pre-existing, found in review**: the home page's first-load JavaScript is about 397 KB gzip against
  C18 §8's 150 KB, and no gate measures it. Not caused by F5a (the Code 128 module is ~0.7 KB gzip).
- **Setting an unconfirmed bet aside** without placing one (U11): today it ends only with a ticket, or
